# Como se compone

## Entidad 

- Se encierra en un rectangulo

## Atributos

- Se encierran en un ovalo

### Atributos simples

- Son tados unicos o atomicos

### Atributos compuestos

- Se componen de atributos mas pequeños

### Atributos multivalor

- Se encierran en un doble ovalo
- Es un atributo que tiene mas datos.

### Atributos derivados

- Se encierran en con un ovalo borde punteado o border:dashed;
- Se obtienen a partir de otros atributos mediante operaciones.

### Primary key

- Son un atributo que identifica de manera unica una referencia de la identidad.
- SE encierra de igual manera en un ovalo pero se subraya el nombre.
